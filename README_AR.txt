حرب الدبابات - نسخة الويب للرفع على GitHub Pages
=================================================

الفولدر ده فيه اللعبة كاملة جاهزة تترفع زي ما هي. متغيرش أسماء الملفات.

خطوات الرفع (أول مرة):
1. اعمل حساب مجاني على github.com لو معندكش.
2. اعمل Repository جديد (زرار New) وسمّيه مثلاً tankwar
   - خليه Public (الـ Pages المجانية محتاجة كده).
3. في صفحة الـ Repository دوس "uploading an existing file".
4. اسحب كل اللي جوه الفولدر ده (مش الفولدر نفسه) وارميه في الصفحة:
   index.html  و  Build  و  TemplateData  و  StreamingAssets  و  .nojekyll
5. استنى الرفع يخلص ودوس "Commit changes".
6. روح Settings > Pages
   - Source: Deploy from a branch
   - Branch: main  والفولدر: / (root)  ودوس Save
7. استنى دقيقة أو اتنين، وهيظهرلك اللينك فوق، شكله كده:
   https://اسمك.github.io/tankwar/

اللعب مع صحابك:
- افتح اللينك > "العب أونلاين مع أصحابك" > اكتب اسمك > "اعمل غرفة جديدة".
- ابعت لصحابك الكود أو الرابط اللي ظاهر في الغرفة (الرابط بيفتح على الغرفة على طول).
- لما الكل يبقى "جاهز" دوس "ابدأ المعركة". الغرفة تاخد لحد 8 لاعبين، وتقدر تضيف لاعبين كمبيوتر.

ملاحظات مهمة:
- اللي عامل الغرفة هو اللي اللعبة شغالة عنده، لو قفل الصفحة المعركة بتخلص للكل.
- أول تحميل حوالي 34 ميجا وبياخد شوية، بعد كده المتصفح بيحفظها.
- لو حد من صحابك خرج في نص المعركة، الكمبيوتر بيكمّل بجيشه.
- لو عايز تحدّث اللعبة بعدين: ارفع الملفات الجديدة فوق القديمة بنفس الطريقة.
